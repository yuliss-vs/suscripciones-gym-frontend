# Frontend - Gestión de Suscripciones Gym

Este es el frontend del proyecto final del Advanced Bootcamp de Solana.

## Características
- Conexión a Phantom Wallet (Devnet).
- Interfaz para que los usuarios se registren y elijan un plan (Básico, Pro, Premium).
- Envío de transacciones reales a la blockchain usando `@solana/web3.js`.
- Diseño moderno y responsivo.
